# Docstring pass

1. Read the whole module before editing anything.
2. List the functions and classes that have no docstring or a long one.
3. Write each docstring as one line saying what the function does, not how.
4. Leave a docstring alone when it already says that in one line.
5. Change only docstring lines; never touch names, signatures or logic.
6. Show the diff of the file when done.
